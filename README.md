## Predict the Success of Bank Telemarketing (Academic( IIT Madras BS Degree) Machine Learning Project)

Course Component: MLP Project (T3 2024)

## Overview:
This project focuses on predicting the success of bank telemarketing campaigns, where customers are contacted via phone calls to promote a bank term deposit. 
The objective is to build a machine learning classification model that predicts whether a customer will subscribe to the product (yes or no) based on demographic, financial, and campaign-related features.


## Dataset Description
The dataset contains information related to direct marketing campaigns of a banking institution.
Each record represents a client contacted during a telemarketing campaign.

- Marketing channel: Phone calls
- Target variable: Whether the client subscribes to a term deposit (yes / no)
- Multiple contacts to the same client may occur
- Dataset Source: Kaggle (Bank Marketing Dataset)
- Dataset is not included in this repository due to licensing restrictions.

## Problem Statement

Given customer and campaign-related features, predict the target variable indicating whether the customer will subscribe to a bank term deposit.

## Evaluation Metric

Model performance is evaluated using: **F1 Score (Macro Average)**

This metric ensures balanced performance across both classes.

## Methodology

- Data loading and preprocessing
- Handling categorical variables and feature encoding
- Exploratory Data Analysis (EDA)
- Model building (baseline and improved models)
- Prediction on test dataset
- Model evaluation using macro F1 score
